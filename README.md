## 德国住宅IP到底在买什么

普通德国 VPS 的 IP 来自数据中心 ASN，OVH、Hetzner、Vultr 这类都算，在风控系统里属于高风险段。表现很具体：TikTok 新号刚发两条就限流，ChatGPT 直接回 “Access denied”，Netflix 提示你在用代理，Stripe、Adyen 把付款标成可疑交易。服务器性能再好也没用，问题出在 IP 的归属属性上。

住宅 IP 的 ASN 归真实 ISP，数据库里 type 字段是 `isp` 或 `residential`，fraud score 通常偏低。LisaHost 的德国段上游走 GTT，但 IP 属性被多个数据库识别为双 ISP 住宅类，这才是它和普通德国 VPS 的本质差别。所以判断一台机器值不值，看的是 IP 检测结果，不是机房地址。

顺带说清楚一个容易忽略的点：住宅线卖的是 **VDS**（Virtual Dedicated Server），不是普通 VPS。资源独占性更高，适合长期跑业务，价格也比同配置 VPS 贵一截。这不是营销话术，看下面的价格表就能感觉到。
